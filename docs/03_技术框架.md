# 技术框架（第一阶段）

第一阶段不依赖 Unity、Godot 或任何特定模型供应商。它先实现一个可独立运行的论坛服务，未来游戏客户端只需要通过 HTTP 和实时事件接入。

## 已建立的模块

```text
forum-runtime/
├─ server.mjs       HTTP API、静态前端、会话与 SSE 实时通知
├─ store.mjs        JSON 开发存储、账号、帖子、回复与数据快照
├─ agents.mjs       受控 AI 账号适配层
├─ data/seed.json   无剧情的开发种子数据
└─ public/          高氛围论坛 Web 壳
```

## 当前可运行能力

- 本地注册账号；
- 创建帖子与回复，数据写入本地 `runtime.json`；
- 多个浏览器窗口的实时更新（SSE）；
- 板块、置顶帖、用户身份、标签与楼层；
- 受权限限制的 AI 用户派发接口；
- Unity/UE/Godot 都可通过 HTTP 使用同一套 API。

## 明确未做的部分

- 生产级登录、密码、邮箱验证、数据库与云部署；
- 文本模型调用与内容审核服务；
- 好友、私信、搜索、举报、附件、库存与任务状态；
- 任何剧情、任务或正式美术资产。

这些模块会在框架稳定后逐项接入。开发时不应把 AI 密钥或审核逻辑放进游戏客户端。

## 本地启动

```powershell
npm start
```

然后访问 `http://localhost:4173`。首次启动会由 `seed.json` 生成本地可删除的 `runtime.json`。
